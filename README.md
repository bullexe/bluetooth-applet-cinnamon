# 🔵 Bluetooth Applet for Cinnamon

A simple and lightweight Bluetooth applet for Cinnamon, inspired by the behavior of Windows and GNOME.

## ✨ Features

* Enable / disable Bluetooth
* Scan nearby devices
* Pair devices
* Connect automatically
* Fully integrated into the system panel

## ⚙️ Requirements

* Linux Mint / Cinnamon
* BlueZ (`bluetoothctl`)
* Bluetooth enabled
* (Maybe you have to install blueman  sudo apt-get blueman)

## 📦 Installation

* Download folder here: https://drive.google.com/drive/folders/1iSLLcABAjMawVY8JghAVRGQjobCrfJMq?usp=drive_link
* Paste the folder in this path: /home/user/.local/share/cinnamon/applets
* Press alt + f2, type R and Enter to restart cinnamon
* Oppen applets app and active 


## ⚠️ Notes

* Some devices require manual confirmation for pairing
* Behavior may vary depending on Bluetooth drivers
